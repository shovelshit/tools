# 猫眼监控紧凑玻璃界面设计

## 背景

猫眼监控工具同时运行在 Web 与 Electron 中，并由 `pages/maoyan` 提供唯一一套共享业务页面。现有功能已经覆盖 Worker 连接、影院与影片选择、通知配置、运行监控和锁座，但页面密度偏低，面板和按钮占用空间过大。

本次视觉重构采用已确认的 B9 方案：轻量银灰背景、缓慢移动的大块几何色板，以及两个克制的毛玻璃一级面板。界面保持工具属性，不加入虚构遥测、网格、扫描线或营销式内容。

## 目标

- Web 与 Electron 继续共享 `pages/maoyan`，不产生平台专属业务页面。
- 将首次连接到启动监控整理成明确的四步流程。
- 桌面端主工作区宽度约为视口的 68%，用背景承接留白，不再铺满窗口。
- 进度面板与主操作面板分离，降低单个大面板的压迫感。
- 缩小桌面表单和操作按钮，同时保留移动端可靠的触控尺寸。
- 保持现有 Worker API、D1/KV 数据、登录态和锁座协议不变。

## 非目标

- 不迁移到 React、Vue 或其他前端框架。
- 不调整 Worker 调度、监控频率或容量架构。
- 不重新设计猫眼官方座位图内容，只调整其外层容器和控制区。
- 不引入 WebGL、3D、视频、粒子系统或第三方 CDN 运行时。
- 不用渐变光球、网格、扫描线、假 HUD 或密集装饰制造科技感。

## 设计原则

1. 页面首先是高频操作工具，紧凑、易扫读和状态清晰优先于装饰。
2. 动态只存在于背景，面板、文字、表单和按钮保持稳定。
3. 毛玻璃只用于进度和主内容两个一级面板，字段和内层区域不继续套卡片。
4. 猫眼红只用于主要动作和错误，青绿色用于在线、成功和当前状态，中性银灰承载结构。
5. Web 与 Electron 的布局和动效一致，平台差异只体现在已有能力与文案上。
6. 所有核心操作在 1024 x 720 桌面窗口和 390 x 844 移动视口中都可完成。

## 信息结构

### 顶部场景栏

场景栏保持轻量且不做独立大卡片，包含：

- 产品标识和当前页面名称。
- Worker 在线状态及已配置地址的简化展示。
- 更多设置入口。

状态必须来自当前 runtime 和真实请求结果。地址只展示主机信息，不显示 Token 或其他敏感参数。

### 四步配置

主流程固定为：

1. 连接服务
2. 选择影院
3. 选择影片
4. 通知与启动

桌面端进度使用独立的窄面板，位于主面板左侧。完成步骤显示青绿色校验，当前步骤使用深色实心圆，未完成步骤保持中性。可返回已完成步骤，未满足依赖的后续步骤不可进入，并显示具体缺失条件。

移动端把进度面板压缩为主面板上方的横向四段进度条，只保留当前步骤标题和 `n / 4`。

### 运行监控

启动后复用相同的两面板结构：

- 进度面板变为运行摘要，显示监控时段和当前状态。
- 主面板显示影院、影片目标、最近检查结果、变化记录与必要操作。
- 停止监控是次级危险操作，需要确认，视觉权重低于启动按钮。

### 锁座

锁座入口位于运行态目标区域，不与常规设置混排。弹窗包含：

- 猫眼会话：Electron 登录、Web 不支持说明、手动上传登录态、会话状态。
- 场次规则：目标日期、模板场次、同厅型与 `+30 分钟` 偏差说明。
- 座位目标：官方座位图、选择结果与只读对比。
- 执行状态：等待场次、尝试锁座、成功、失败和通知结果。

只有进入实际锁座尝试或严重异常时强化红色告警。无论锁座成功或失败，都沿用现有通知行为。

## 布局尺寸

### 桌面端

- 页面内容宽度约为可用视口的 `68%`，并设置合理的最小、最大宽度，避免极宽屏无限拉伸。
- 场景栏高度约 `40-48px`，不使用高大的应用标题区。
- 两个一级面板间距约 `12-16px`。
- 进度面板宽度约 `180-208px`；主面板占据剩余空间。
- 主按钮和普通按钮视觉高度约 `28-32px`，紧凑状态可降至约 `24px`，但焦点区域不能被裁切。
- 单行输入框高度约 `32px`；分段按钮高度约 `28px`。
- 一级面板圆角不超过 `8px`，字段圆角约 `3-4px`。

视觉稿中的 `23px` 按钮和 `27px` 输入框是缩放画布内的目标比例，代码实现以可读性和浏览器实际像素为准，不机械照搬导致文字或焦点环拥挤。

### 平板与窄桌面

- 逐步扩大工作区占比，避免内容小于可读下限。
- 保留左侧进度面板，必要时缩窄其辅助文案。
- 长影院名、Worker 地址和错误信息允许换行，不推挤主操作。

### 移动端

- 改为单列布局，工作区占满减去安全边距后的宽度。
- 进度改为顶部横向条，与主面板仍保持视觉分离。
- 标签置于输入框上方，选项可换行或使用全宽分段控制。
- 触控按钮和输入框高度至少 `40px`；底部操作区适配系统安全区域。
- 锁座座位图允许横向平移和缩放，工具按钮不覆盖座位。

## 视觉系统

### 背景

背景使用浅银灰底色与 3-4 块大尺寸实色几何色板：

- 主冷色板：低饱和青灰。
- 高光色板：接近白色的冷灰。
- 品牌色板：低占比猫眼红。
- 色板通过模糊形成柔和边界，但不能呈现为圆形光球或装饰性渐变。

背景承担页面留白，因此工作区外不再增加信息卡或装饰文字。

### 面板

两个一级面板使用：

- 半透明浅色背景。
- 约 `18px` 的背景模糊和轻度饱和度调整。
- 低对比白色边界、轻阴影和内侧高光。
- 不透明度必须保证浅色几何板经过时正文仍有足够对比度。

字段、详情行、状态信息使用分隔线和间距组织，不创建嵌套毛玻璃卡片。

### 颜色语义

| Token | 建议值 | 用途 |
|---|---|---|
| `surface-page` | `#BDC9CF` | 页面银灰底色 |
| `surface-glass` | `rgba(247, 250, 251, 0.64)` | 一级玻璃面板 |
| `surface-field` | `rgba(255, 255, 255, 0.56)` | 字段与选中分段 |
| `border-glass` | `rgba(255, 255, 255, 0.72)` | 一级面板边界 |
| `border-subtle` | `rgba(92, 111, 122, 0.24)` | 分隔线和字段边界 |
| `text-primary` | `#1D262C` | 主文本 |
| `text-secondary` | `#66747D` | 辅助文本 |
| `action-primary` | `#EF4B52` | 主按钮和错误 |
| `status-positive` | `#087F7A` | 在线、成功和当前状态 |
| `status-warning` | `#B46D12` | HTTP 风险和等待 |

代码中组件只引用语义变量，不直接散落基础色值。文字字间距统一为 `0`。

### 图标与控件

- 优先使用项目已有图标库；没有依赖时使用本地 SVG 或清晰文字，不引入远程字体图标。
- 常见操作使用图标按钮并提供可访问名称和 tooltip。
- 文本按钮只用于明确命令，如“连接”“上一步”“开始监控”。
- 所有 hover、focus、disabled、loading 和 error 状态尺寸稳定，不能引发布局跳动。

## 动态背景

- 仅几何色板使用 `transform` 和必要的 `opacity` 动画，不动画布局属性或滤镜。
- 单次周期在 `14-19s` 之间，不同色板错开节奏。
- 单轴最大位移不超过 `24px`，只允许轻微旋转，避免视觉晕动。
- 动画速度约比上一版慢速方案快 30%，但不追随鼠标、不响应滚动。
- 页面或 Electron 窗口失焦时暂停背景动画，重新聚焦后继续。
- `prefers-reduced-motion: reduce` 下完全停用背景和状态装饰动画。
- Web 与 Electron 共用同一份 CSS 与可见性控制逻辑。

## 数据与交互边界

本次不改变 API 请求和保存语义：

- Worker 连接状态来自当前 runtime 与 `/api/status`。
- 配置步骤完成度由已有 Worker profile、影院、影片与通知配置计算。
- 自动保存状态由真实请求生命周期驱动，不模拟成功。
- 监控和锁座倒计时使用已有 cron、规则和执行状态。
- Web/Electron 差异继续由 `runtimeInfo` 控制，不复制页面模板。

加载超过 300ms 才显示进度，提交类操作禁止重复触发。错误提示保留在相关字段或操作附近，同时写入现有记录区。任何错误文本都不得包含 Token、Cookie、`mtgsig` 或完整登录态。

## 实现边界

1. 将语义变量映射为 `pages/maoyan/style.css` 的 CSS custom properties。
2. 保留现有语义化元素、业务元素 ID 和表单提交路径，降低 `app.js`、`lock.js` 回归风险。
3. 只在布局语义需要时调整 `pages/maoyan/index.html`，不复制 Web/Electron 模板。
4. 在共享脚本中根据页面可见性和窗口焦点控制背景动画暂停状态。
5. Electron 继续直接打包共享静态页面，不增加在线资源依赖。

## 可访问性

- 正文与动态背景之间达到 WCAG AA 对比度。
- 所有交互元素有明确键盘焦点，焦点环至少 `2px` 且不被裁切。
- 成功、警告和错误同时使用文字或图标，不能只依赖颜色。
- 支持键盘完成连接、影院选择、影片选择、通知配置和弹窗关闭。
- tooltip 不承载完成任务所必需的信息。
- 座位图外围控制提供可访问名称，官方座位图本体维持现有只读语义。

## 验证策略

### 视觉回归

- 使用 Playwright 截图检查 `1440 x 900`、`1024 x 720`、`768 x 1024` 和 `390 x 844`。
- 覆盖连接、四步配置、运行态和锁座弹窗。
- 检查长影院名、长错误信息和最大数量状态下没有溢出或遮挡。
- 对背景区域执行像素检查，确认几何色板可见，截图前后位置有变化，面板内容没有位移。

### 交互回归

- 保留现有 DOM ID 与主要事件路径，运行 Worker 和 Electron 现有测试。
- 验证四步完成度、返回修改、提交防重和运行态切换。
- 验证 Web 登录按钮仍明确不可用，Electron 登录与手动上传仍可用。
- 验证主题重构不改变 Worker URL、Token、配置和锁座请求内容。
- 验证窗口失焦及 `prefers-reduced-motion` 都能暂停动态背景。

## 验收标准

- 桌面主工作区约占视口 68%，进度与主面板独立，窗口留白由动态背景承接。
- 页面只包含两个一级毛玻璃面板，不出现卡片套卡片。
- 桌面按钮和字段明显比旧版紧凑，移动端仍满足触控尺寸。
- 背景动画周期为 14-19 秒、位移不超过 24px，只使用合成友好属性。
- 动画在失焦和减少动态效果时暂停，面板和内容始终静止。
- Web 与 Electron 共享一套页面和交互逻辑，不依赖第三方 CDN。
- 现有监控、通知、登录态上传、座位选择和锁座流程无行为回归。
