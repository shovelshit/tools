# 猫眼场次座位缩略图设计

## 目标

在猫眼影院场次监控页中，用户点击某一场次后按需展示该场的座位缩略图。缩略图用于判断可选座位的大致分布，不创建订单、不锁座、不使用或上传用户本地登录态。

## 范围

- 场次表保留现有影片和日期分组。
- 每个场次 chip 改为可点击控件；首次点击展开该场的座位图，再次点击收起。
- 图中区分可选、已售或不可选、过道和缺失位置；不显示真实用户身份、订单信息或价格。
- 单场加载失败仅在该场展开区显示错误，不影响其他场次和监控配置。

不包含：锁座、选座、支付、自动刷新座位图、持久化座位数据、将本地 Chromium 会话传给 Worker。

## 数据流

1. `GET /api/shows` 在现有场次数据中额外返回每条排片的 `seqNo`。
2. 用户点击场次 chip，前端请求 `GET /api/seats?cinemaId=<id>&movieId=<id>&seqNo=<id>`，仍使用 `X-Token` 鉴权。
3. Worker 验证三个参数为数字，生成受控的 `https://www.maoyan.com/xseats/<seqNo>?movieId=<movieId>&cinemaId=<cinemaId>` URL。
4. Worker 仅以匿名请求获取该公开选座页，限制为 `www.maoyan.com` HTTPS、12 秒超时、最多 5 次重定向和非 2xx 失败。
5. Worker 解析页面中的座位元素，归一化为 `{ section, row, column, status }`。只返回渲染缩略图所需的坐标和状态，不转发原始 HTML 或 Cookie。
6. 解析结果按 `cinemaId:movieId:seqNo` 缓存在 KV 60 秒。缓存仅保存缩略图数据，过期后由下一次用户点击重新获取。
7. 前端为展开的场次创建固定尺寸的 CSS Grid。空列保留为过道或空白格，状态以色块和简短图例表达；场次收起时移除该 DOM，前端内存结果可在本次页面会话复用。

## 接口

成功响应：

```json
{
  "ok": true,
  "sections": [
    {
      "name": "1",
      "rows": [
        { "row": 6, "seats": [{ "column": 18, "status": "available" }] }
      ]
    }
  ]
}
```

`status` 仅允许 `available`、`unavailable`、`selected` 和 `empty`。匿名页面不应产生 `selected`，但客户端接受它以兼容页面数据。

错误响应不暴露猫眼 HTML、请求 URL 中的敏感参数或上游响应内容：

```json
{ "ok": false, "error": "座位图暂不可用" }
```

## 前端交互

- 未展开：场次 chip 有按钮语义和“查看座位图”标题。
- 加载中：该场次下方显示稳定高度的加载占位，chip 禁用以防并发重复请求。
- 成功：显示影厅区块、屏幕方向提示、座位网格和三态图例。超出容器时横向滚动，避免压缩到不可辨认。
- 失败：显示“座位图暂不可用”，提供重试按钮；重试不影响其他场次。
- 仅在用户显式点击后请求，不在影片展开、页面恢复或定时检查期间请求座位图。

## 安全与可靠性

- `seqNo`、`movieId`、`cinemaId` 均限制为十进制数字，禁止客户端提供完整 URL。
- 上游请求和重定向逐跳校验固定主机，禁止 Worker 成为开放代理。
- 响应设置短缓存；不向 KV 写入 Cookie、HTML、座位价格或用户数据。
- HTML 解析失败、匿名访问受限、超时或上游变更时返回统一错误；不会影响现有 `/api/shows`、监控任务或推送。

## 验证

- 使用已有影院和已知 `seqNo` 验证接口返回仅包含允许字段和状态枚举。
- 验证非法 ID、跨域重定向、超时和无座位页均返回安全错误。
- 验证点击一场只触发一次请求，收起/展开使用本页缓存；错误后点击重试才再次请求。
- 用桌面和移动宽度检查网格没有溢出文本或重叠，且全程没有锁座或支付请求。
