# Lynkco-push 配置教程设计

## 目标与范围

将独立的 VitePress 教程站缩减为单项目教程。首页和侧栏只展示“Lynkco-push 配置教程”。新地址为 `/lynkco-plus`，不提供 `/lynkco` 的旧页面或重定向。

删除教程站中猫眼、应用商店、蓝牙以及旧领克四篇 Markdown 页面和仅供这些页面使用的图片；不修改工具箱首页 `pages/index.html` 或工具本身。删除范围限于教程站，其他仓库内容不受影响。

## 页面与素材

- `guide/index.md` 改为单项目入口，指向 `/lynkco-plus`。
- `guide/.vitepress/config.mts` 的站点标题、侧栏改为 Lynkco-push 教程；保留返回工具箱导航。
- `guide/lynkco-plus.md` 用九张已裁掉顶部状态栏的 ProxyPin 截图，按 App Store 安装、证书安装与信任、开启抓包的时间顺序撰写操作说明。使用现有 `GuideFigure` 组件的图片放大能力，配准确的替代文本和图注。
- 原有九张 WebP 与新增六张脱敏后的 WebP 放在 `guide/public/images/lynkco-plus/`。不复制原视频、总览图、备份图、原始附图或任何含账号/请求数据的帧。
- 正文提示根证书及 VPN 授权仅用于自己的设备与已获授权流量。截图不暗示安装、信任或抓包已由读者实际完成。

## 后续抓包与导出

在原有九步之后，按用户提供的六张手机截图扩为四节：

1. “1、抓包”只包含原有九步 ProxyPin 安装与抓包启动。
2. “2、验证 refresh”说明打开领克 App，在 ProxyPin 搜索 `refresh`，确认请求是否出现。
3. “3、获取分享请求”说明在领克 App 首页选择任意动态并点击分享，再回 ProxyPin 搜索 `getShareCode`，确认请求是否出现。
4. “4、导出 HAR”说明在 ProxyPin 请求列表打开右上角菜单，选择“视图导出”中的 HAR，保存文件并本地核对包含目标请求。

六张新截图保持操作顺序，裁去手机状态栏，适当裁掉无关空白；导出两图保留完整 ProxyPin 工具栏、导出菜单或弹窗和底部导航。公开图用不透明遮挡隐藏 `deviceId`、动态作者头像/昵称和导出界面背景的无关请求，不发布原始 PNG。HAR 可能包含令牌、Cookie、设备标识及其他流量，正文提醒用户仅在自己的设备和获授权的流量中操作，不要公开上传未经检查的 HAR。

## 验证

- 站点构建后首页和 `/lynkco-plus` 可访问，十五张图片均可加载；`/lynkco`、`/maoyan`、`/store`、`/ble` 不生成页面。
- 更新站点测试，核对标题、导航、步骤顺序、图片路径、替代文本、404 与不含私密素材；运行构建和测试，并在本地预览桌面/手机布局。
- 新增的六张截图都应在页面按操作顺序可加载；检查导出构建不含原始 PNG 或 HAR，并人工核对遮蔽后的每张公开图。
