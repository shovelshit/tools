# VitePress 教程视觉与配图改进设计

## 目标与范围

在已有 `guide/` VitePress 教程站上实现用户选定的 A 版“清爽阅读”风格：正文更易扫描，真实界面截图直接出现在相关步骤下。配图以真实截图为主，只有先后关系或原理无法从截图读懂时才补一张简洁示意图。保留四篇现有教程及其路由、内容事实、VitePress 默认导航和站点独立构建方式；不改 Worker、工具业务页面、工具箱首页的链接目标，也不部署 Pages/DNS。

## 视觉设计

- 保持单列教程首页与默认文章侧栏、移动端目录。首页用更明确的项目名称、简短用途和克制的分隔线组织四个入口，不新增卡片墙、时间线或营销式头图。
- 文章使用舒适的正文行宽、适度增大的标题层级和段落间距、低对比度分隔线；步骤以简单数字标识，真实截图紧跟其对应步骤。配色以中性底色、深绿链接和少量暖色步骤强调组成，避免整页单色或大面积渐变。
- 图片宽度不超过正文栏；手机屏幕上按容器宽度缩放，不产生水平滚动。图片下方是“图 N · 画面/操作”的短说明。可点击查看大图，支持键盘关闭和移动端退出；若图片无法加载，替代文字与正文仍足以完成操作。
- 不把图片当成可操作控件，也不让图片取代文字步骤。截图是当前界面示例，界面改版后需要更新；流程示意明确标注“不代表实际按钮布局”。

## 配图策略

- 猫眼：从仓库当前公开页面截取不含真实访问令牌的连接界面；后续监控/锁座界面只有在可用的无凭据测试状态下才能截图，否则保留现有文字说明。
- 应用商店：从当前公开登录页面截取不含真实密钥的登录界面；资源列表/预览只有在安全、可公开的测试数据下才能截图，否则不放虚构内容。
- 领克、BLE：检查其当前公开上游仓库是否提供真实界面截图及可用许可/出处。能核实的图片注明来源；无法核实或存在账号、设备、会话信息时不收录，必要时用简短流程示意补足概念关系，不伪造 App 或小程序界面。
- 图片纳入 `guide/public/images/`，保留必要的来源说明，使用压缩后的 WebP/PNG，避免将凭据、会话、个人信息和工作区私有文档带入静态产物。截图取材与文章叙述相符，优先裁去无关区域而非做误导性的重绘。

## 实现边界与验证

在 `guide/.vitepress/theme/` 内复用默认主题做轻量 CSS 与图片放大交互；不引入大型主题或外部运行时服务。文章 Markdown 内使用图片与短图注，必要时用一个局部复用组件处理可访问的放大行为；没有图片的段落仍正常阅读。保留 `guide/` 独立锁文件、base `/`、构建输出 `.vitepress/dist/`。

验证包括：现有构建及站点测试；四篇页面与图片 URL 检查；桌面与 320/390px 手机视口的正文、图片、图注、目录及放大/关闭交互；图片加载失败时替代文字；产物不含凭据与忽略的本地资料。线上域名与根工具箱首页的发布路径不在此次验证范围内。
